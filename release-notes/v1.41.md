## 新機能

### リモコンの再生操作用のキーに対応しました

テレビ付属のリモコンや Fire TV のリモコンにある再生操作用のキーが、内蔵プレーヤーの再生画面で使えるようになりました。再生コントロールを開かずにその場で働き、切り替えやスキップの結果は短いメッセージで知らせます。

| キー | 動作 |
|---|---|
| 早戻し / 早送り | 押すたびに **10秒戻る / 30秒進む**（一時停止中も同じ） |
| 前 / 次 | 「最初から再生」/「次のエピソード」ボタンと同じ |
| 字幕 | 字幕のON/OFF（CCボタンと同じ） |
| 音声切換 | 主音声 / 副音声の切り替え（音声ボタンと同じ） |
| 停止 | 再生をやめて前の画面に戻る |

どのキーがあるかはリモコンによって違います。押しっぱなしにしても連続では動かず、1回押すごとに1回分だけ動きます。ライブ視聴では早戻し / 早送りと前 / 次は働きません。テレビ側が別の用途に使っているキーは、アプリには届きません。

**ご注意: Fire TV のリモコンの早戻し / 早送りボタンの動きが変わります。** これまでは左右キーと同じ働き（シークバーの目盛りを動かし、決定で確定）でしたが、押すたびにその場で10秒戻る / 30秒進むようになりました。シークバーで位置を選んでいる最中に押したときは、これまでどおり目盛りが1つ動きます。

### 詳細画面から録画をプロテクトできるようになりました

詳細画面の「番組情報」の右に **プロテクト** ボタンが増えました。プロテクトした録画は、EPGStation の自動削除の対象から外れます。残しておきたい録画を、テレビの前から守れます。

ボタンを押すと、何を対象にするかを選ぶ一覧が開きます。

| 選択肢 | 対象 |
|---|---|
| この番組をプロテクト / この番組のプロテクトを解除 | いま開いている録画1本 |
| シリーズをプロテクト / シリーズのプロテクトを解除 | 同じシリーズの録画すべて |

シリーズの範囲は連続再生やエピソード一覧と同じで、番組名から取り出したシリーズ名で集めます。シリーズの選択肢には対象の本数が出るので、確かめてから実行できます。同じシリーズの録画がほかに見つからないときは、「この番組」の選択肢だけが出ます。

プロテクト済みの録画には、サムネイルの右上に南京錠のマークが付きます。メイン画面・検索画面・詳細画面・再生画面のエピソード一覧のどこでも見分けられます。

プロテクトした録画は、カードの長押しからも削除できなくなります。削除するときは、先にプロテクトを解除してください。

EPGStation v1 に接続している場合、プロテクトボタンは出ません（南京錠の表示のみ）。

### メイン画面にディスクの使用量が出るようになりました

メイン画面右上の「EPGStation」の文字の下に、録画の保存先がどれだけ埋まっているかを示す棒が出るようになりました。白い部分が使用済み、灰色の部分が空きで、あとどれくらい録画できるかの目安になります。

![ディスク使用量の棒](https://raw.githubusercontent.com/daig0rian/epcltvapp/v1.41/screenshots/disk-usage-bar.png)

棒の中の文字は **使用量/容量 · 使用率** の順です。使用率が100%になると、`Used` が `Full` に変わります。EPGStation に録画の保存先を複数設定しているときは、保存先ごとに1本ずつ（4本まで）並び、先頭の `Disk` が保存先の名前に変わります。

容量は、EPGStation の Web 画面に出る数字より少し小さいことがあります。録画に使えない領域を除いて数えているためで、空きがなくなったときにちょうど100%になります。

表示は、メイン画面を開いたとき・ほかの画面から戻ってきたとき・カードの長押しで録画を削除したときに更新されます。メイン画面を出したままにしている間も、5分ごとに更新されます。

## 改善

- 録画した放送そのままのTSの再生で、シークが選んだ位置へ正確に着地するようになりました。これまでは録画によって着地が数十秒ずれることがありました。レジューム再生で前回の位置へ戻るときも同じです。
- 詳細画面や再生画面から検索画面へ戻ったときに、検索結果を最新の状態へ更新するようになりました。
- 検索画面からメイン画面へ戻ったときも、ほかの画面から戻ったときと同じく「ライブ視聴」「録画中」「最近の録画」を更新するようになりました。
