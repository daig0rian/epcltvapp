## 新機能

### アプリの中からアップデートできるようになりました

このアプリはストアで配布していないため、これまでは新しいバージョンが出るたびに GitHub から APK を取ってきて端末へ入れ直す必要がありました。この一連の作業を、アプリの中だけで済ませられるようになりました。

メイン画面の「設定」の行に **アップデートを確認** が増えています。選ぶと GitHub へ接続してよいかを尋ねる画面が出るので、「接続して確認」を選んでください。新しいバージョンがあればその内容が表示され、「更新する」を選ぶとダウンロードから端末のインストーラーの起動まで続けて進みます。最新であれば「お使いの v1.38 が最新です」と表示されます。

![アップデートの確認画面](https://raw.githubusercontent.com/daig0rian/epcltvapp/v1.38/screenshots/update-consent.png)

**このアプリが自分からインターネットへ出ることはありません。** 起動時のチェックも定期的な確認もせず、確認した結果を端末に残すこともしません。新しいバージョンが出たことに自動で気づく仕組みはありません。

インストールには「不明なアプリのインストール」の許可が必要です。許可がないときは案内が表示されます。多くの機種ではそこから設定画面へ直接移動できますが、Fire TV ではこの設定画面をアプリから開けないため、表示される手順に沿って手動で許可してください。

この機能が入るのは v1.38 からです。**v1.37 以前から v1.38 へ上げるときは、これまでどおり APK を手で入れてください。** 次のアップデートからアプリの中で完結します。

詳しい手順は[操作マニュアルの7章](https://github.com/daig0rian/epcltvapp/blob/v1.38/MANUAL.md#7-アプリをアップデートする)を参照してください。

## 不具合修正

- `TVアニメ『作品名』#8` のように、ジャンルの名乗りに続けて作品名を『』で囲む番組名で、シリーズ名が「TVアニメ」の部分だけになっていました。この形式の別作品どうしが同じシリーズにまとまってしまい、連続再生とエピソード一覧が正しく働かない状態だったのを修正しています。
